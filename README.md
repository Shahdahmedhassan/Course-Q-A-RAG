# Course Q&A RAG System

🔗 **Live App:** [(https://course-qa-rag.streamlit.app](https://course-q-a-rag-zmvpvntiqpydq3rysdutj5.streamlit.app/))

A Retrieval-Augmented Generation (RAG) system that answers student questions using course materials
from multiple courses and file formats (PDF, CSV, DOCX, TXT), with source attribution for every answer.

---

## Overview

This project builds an end-to-end RAG pipeline:

1. Extracts text from course materials in different formats (PDF, CSV, DOCX, TXT)
2. Cleans and splits the text into chunks
3. Generates embeddings for each chunk and stores them in a vector database
4. Retrieves the most relevant chunks for a given student question
5. Uses an LLM to generate an answer grounded strictly in the retrieved content
6. Displays the answer along with the exact course and file it came from

---

## Tech Stack

| Component            | Tool / Library                                    |
|-----------------------|----------------------------------------------------|
| Text extraction       | `pypdf`, `python-docx`, `pandas`                   |
| Embeddings            | `sentence-transformers` — `all-MiniLM-L6-v2`       |
| Vector database       | `faiss-cpu` (FAISS)                                |
| Answer generation LLM | `transformers` — `google/flan-t5-base` (local, free) |
| Web app / UI          | `streamlit`                                        |
| Notebook / training   | Jupyter Notebook (built and run on Kaggle)         |

The generation model can optionally be swapped for the OpenAI API (see the commented-out cell in the
notebook) if higher-quality answers are needed.

## How to Use

### 1. Build the model (run the notebook)

1. Open `RAG_Course_QA_Pipeline.ipynb` (works on Kaggle, Colab, or locally in Jupyter).
2. Upload the `data/` folder (or your own course materials, keeping the same structure:
   `data/<course_name>/file.pdf|.csv|.docx|.txt`).
3. Update `DATA_DIR` in the "Set up paths" cell to point to your data location.
4. Run all cells in order. This will:
   - Extract, clean, and chunk the text
   - Generate embeddings and build a FAISS vector store
   - Save everything into a `rag_model/` folder (and a `rag_model.zip` for easy download)

### 2. Run the app

```bash
pip install -r requirements.txt
streamlit run app.py
```

Make sure the `rag_model/` folder (containing `vector_store.faiss`, `chunks.pkl`, and `config.json`)
is placed in the same directory as `app.py` before running.

### 3. Ask questions

- Open the app in your browser (Streamlit will print a local URL, e.g. `http://localhost:8501`).
- Optionally filter by course and adjust how many chunks are retrieved from the sidebar.
- Type a question in the chat box — the answer will be generated strictly from the course
  materials, with the source course/file shown underneath.

## Notes

- The included `data/` folder contains sample lecture content for demonstration — replace it with
  your real course materials using the same folder structure.
- The default models (`all-MiniLM-L6-v2` for embeddings, `flan-t5-base` for generation) are free and
  run locally with no API key required.
- If the answer isn't found in the retrieved course material, the system will say so rather than
  making something up.
